# 문제 해결

## 설치

| 증상 | 원인 · 조치 |
|---|---|
| `winget install` 시 패키지를 찾지 못함 | 소스 캐시가 오래됨 — `winget source update` 후 재시도 |
| `winget`이라는 명령을 못 찾음 | winget 미설치 — Microsoft Store에서 **"앱 설치 관리자"** 설치 (Windows 10 1809 미만은 미지원) |
| `choco install`이 "package not found" | `choco search nshiftspace`로 노출 확인. 피드 반영 지연이면 잠시 후 재시도 |
| `choco`가 "액세스가 거부되었습니다" | Chocolatey는 **관리자 권한 PowerShell**이 필요합니다 |
| 업그레이드/제거가 파일 잠김으로 실패 | 트레이 아이콘 우클릭 → 종료 후 재시도. (winget에서 특히 발생 — 자동 종료 처리가 없음) |

## 실행

| 증상 | 원인 · 조치 |
|---|---|
| 실행해도 아무 일도 안 일어남 | 정상입니다. 창이 없는 트레이 프로그램입니다. 작업 표시줄의 **∧** 를 눌러 숨겨진 아이콘을 확인하세요 |
| 트레이 아이콘이 안 보임 | 숨김 영역에 있을 수 있습니다. explorer 재시작 후에는 자동 복구됩니다 |
| 두 번 실행했는데 하나만 뜸 | 정상입니다 — 뮤텍스로 중복 실행을 막습니다 |
| `nshiftspace` 명령을 못 찾음 (winget) | 별칭이 생성되지 않았을 수 있습니다 → [자동 실행 설정 1단계](Autostart#1단계--가리킬-exe-경로-확정) 참고 |
| 백신이 차단함 | CRT 없이 빌드된 초소형 exe라 휴리스틱 오탐이 드물게 발생합니다. [Releases](https://github.com/SosomLab/nexa-shortcut/releases)의 파일과 SHA256을 대조한 뒤 예외 등록하세요 |

## 단축키가 안 먹을 때

**증상별로 원인이 다릅니다. 위에서부터 확인하세요.**

### 1. 특정 창에서만 안 된다 → 관리자 권한 문제

작업 관리자, 승격된 터미널, 일부 설치 프로그램 위에서 안 된다면 **정상 동작**입니다.
Windows 보안 정책(UIPI)상 일반 권한 프로그램의 단축키는 관리자 권한 창에 전달되지 않습니다.

**해결**: nShiftSpace를 관리자 권한으로 실행하세요.
로그인 시 자동 승격 실행 →
[자동 실행 설정 — 방법 C (작업 스케줄러)](Autostart#방법-c--작업-스케줄러--관리자-창에서도-단축키가-먹게-하려면)

### 2. 어디서도 전혀 안 된다 → 단축키 선점 충돌

다른 프로그램이 Shift+Space를 이미 등록했을 수 있습니다.
`RegisterHotKey`는 먼저 등록한 쪽이 이깁니다.

의심 대상: 다른 한/영 전환 유틸리티(원조 jwShiftSpaceKey 포함), 매크로 프로그램,
게임 오버레이, 일부 IME 도구.

**해결**: 의심되는 프로그램을 종료한 뒤 nShiftSpace를 재시작해 보세요.

### 3. 한/영은 바뀌는데 입력이 이상하다 → IME 설정

nShiftSpace는 한/영 키를 눌러줄 뿐이고, 실제 전환은 Windows IME가 합니다.

**확인**: `설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션 →
Microsoft 입력기 → 옵션` 에서 한/영 전환 키 설정을 확인하세요.

### 4. 트레이 아이콘은 있는데 반응이 없다

프로그램을 종료했다 다시 실행해 보세요. 그래도 안 되면 재부팅 후 재시도.
계속된다면 [이슈로 알려주세요](https://github.com/SosomLab/nexa-shortcut/issues/new).

## 자동 실행

| 증상 | 원인 · 조치 |
|---|---|
| 업그레이드 후 자동 실행이 안 됨 | 바로가기가 끊어졌을 수 있습니다. `Links` 별칭 경로 대신 `Packages` 실제 경로를 가리켰을 때 발생 → [자동 실행 설정](Autostart) 1단계부터 다시 |
| 예약 작업(방법 C)이 실행되지 않음 | 작업 스케줄러에서 `nShiftSpace` 작업의 **마지막 실행 결과**를 확인하세요. `-ExecutionTimeLimit 0`을 빠뜨리면 3일 후 종료됩니다 |
| 로그인 시 검은 창이 잠깐 뜬다 | 방법 B(Run 키)에서 경로를 큰따옴표로 감싸지 않은 경우 발생할 수 있습니다. 재등록해 보세요 |
| 시작 프로그램에 등록했는데 목록에 없다 | 작업 관리자 → 시작 프로그램 탭은 방법 A·B만 표시합니다. 방법 C는 작업 스케줄러에서 확인 |

## 그래도 해결이 안 되면

[GitHub Issues](https://github.com/SosomLab/nexa-shortcut/issues)에 알려주세요.
아래 정보를 함께 적어주시면 빠르게 확인할 수 있습니다.

- Windows 버전 (`winver` 실행 결과)
- 설치 방법 (winget / Chocolatey / zip)
- nShiftSpace 버전
- 증상이 나타나는 구체적인 상황 (어떤 창에서, 언제부터)
